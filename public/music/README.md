# ShockBot album

Drop new mp3 files here as `track-05.mp3`, `track-06.mp3`, … then append matching entries to `tracks.json`.

Example entry:

```json
{ "id": "track-05", "file": "track-05.mp3", "title": "ShockBot · Track 5" }
```

Replace the placeholder title with the real song name when you know it. The CD player reloads this list on boot, so no code change is required.
