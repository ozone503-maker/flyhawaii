Thank-you clips for the delivery arrival scene

1. Copy the video here, for example thanks-01.mp4 (vertical 9:16, 4 to 8 seconds, MP4 H.264 with AAC audio)
2. Add an entry to clips.json:
   { "clips": [ { "id": "thanks-01", "file": "thanks-01.mp4" } ] }
   Separate several entries with commas
3. Rebuild and deploy

An empty list means no clips play and deliveries use the normal arrival scene
